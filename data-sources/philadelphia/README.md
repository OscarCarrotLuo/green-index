# Philadelphia boundary inputs

Downloaded 2026-11-04 for `scripts/build-districts.py`. Used only to group the 384 research tracts for display; no research values are recomputed from imagery.

- `planning_districts.geojson` — City of Philadelphia Planning Districts (18), City Planning Commission, via ArcGIS Online:
  https://services.arcgis.com/fLeGjb7u4uXqeF9q/arcgis/rest/services/Planning_Districts/FeatureServer/0
- `neighborhoods.geojson` — Philadelphia neighborhoods (Azavea / OpenDataPhilly), used only for familiar place names:
  https://github.com/opendataphilly/open-geo-data/tree/master/philadelphia-neighborhoods
